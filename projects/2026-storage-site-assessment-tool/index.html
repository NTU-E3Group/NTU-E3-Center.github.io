Projects Energy Storage Site Assessment Tool

Ongoing Research Project

Development of a Decision-Support Tool for Energy Storage Site Assessment

儲能案場評估輔助工具建置

Duration
2026–2027
Funder
Yiho International Co., Ltd. (怡和國際股份有限公司)

An industry-academia project with Yiho International Co., Ltd. to build a decision-support tool for evaluating battery energy-storage sites. It consolidates the company's existing, Excel-bound workflow — load-data processing, capacity sizing, revenue and financial modeling, and scenario comparison — into a standardized, version-controlled tool that speeds internal assessment and produces consistent proposal reports.

About this project

Evaluating a battery energy-storage project means pulling together a lot of moving parts — a client's electricity-use data, candidate capacity configurations, revenue and financial projections, and side-by-side scenario comparisons. Yiho International Co., Ltd. already has well-developed practices and financial logic for this. As case volume grows and parameters change often, this industry-academia project (2026–2027), led by the E3 Center, helps turn that established know-how into a purpose-built assessment tool — making the same trusted expertise faster to apply and easier to scale.

The goal is a support tool that mirrors and streamlines Yiho's existing workflow end to end: importing and organizing load data with basic time-of-day and monthly analysis and visualization; comparing storage capacity configurations and benefit scenarios; integrating the existing revenue and financial calculations for parameter-by-parameter comparison; codifying the current practical decision rules into consistent calculation and output logic; and generating standardized report and presentation formats for both internal review and external proposals. A final strand covers parameter updates, version management, and usage guidance so the tool stays maintainable after handover.

The project is run collaboratively — through regular meetings and continuous communication to confirm requirements, adjust features, and accept deliverables, with each stage refined against real usage. In practical terms it brings the E3 Center's energy-systems and techno-economic modeling to bear on a storage developer's day-to-day evaluation work, improving both the efficiency and the consistency of how storage projects are assessed and proposed.

評估一個儲能案場，需要整合眾多環節——客戶的用電資料、可能的容量配置、收益 與財務試算，以及各情境的並列比較。怡和國際股份有限公司在這方面已具備成熟的 實務作業與財務試算邏輯。隨著案件數量增加、參數又頻繁調整，本建教 合作計畫（2026–2027）由 E3 中心主持，協助將這套既有的實務知識，轉化為專用的 評估輔助工具，讓這套值得信賴的專業能更快速地應用、更易於擴展。

計畫目標是打造一套能完整反映並精簡怡和現行流程的輔助工具：匯入並整理用電 資料，提供基本的時段與月份負載分析與視覺化；比較不同儲能容量配置與效益情境； 整合既有的收益與財務試算，支援不同參數條件下的比較；將現行實務的判斷流程 規則化，建立一致的計算與輸出邏輯；並產出對內檢視與對外提案所需的標準化報表 與簡報格式。最後一項工作則涵蓋參數更新、版本管理與使用流程建議，使工具在交付 後仍可持續維護。

計畫採協作方式推動——透過定期會議與即時溝通確認需求、調整功能與驗收成果， 各階段並依實際使用情況逐步修正。就實務而言，本計畫將 E3 中心的能源系統與 技術經濟建模能量，導入儲能開發商的日常評估工作，同時提升儲能案場評估與提案的 效率與一致性。
